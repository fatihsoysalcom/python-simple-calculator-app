# Python Simple Calculator App

This Python script creates a simple command-line calculator. It demonstrates basic arithmetic operations using functions, user input handling, and conditional logic. The calculator allows users to perform addition, subtraction, multiplication, and division.

## Language

`python`

## How to Run

Save the code as a Python file (e.g., calculator.py) and run it from your terminal using: python calculator.py
